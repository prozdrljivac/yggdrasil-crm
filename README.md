# YggdrasilCRM

YggdrasilCRM helps the owner of Huginn & Muninn manage potential work, client
details, invoices, and expense documents in one place. It covers software
development, headhunting, and mentoring services.

## Planned features

- **Opportunities:** track applications, outreach, discussions, and outcomes.
- **Clients and contacts:** reuse company and individual records from prospect
  through client to invoicing.
- **Service catalog:** save hourly, daily, and fixed-price service templates.
- **Invoices:** prepare multilingual invoices, download PDFs, and keep issued
  versions unchanged.
- **Expense documents:** store receipts and PDFs and track accountant handoff.
- **Business profile:** reuse issuer details and invoice defaults.

The MVP targets one owner and must support core workflows on mobile.

## Status

Development is in progress. The current application provides a local development
shell; the business features listed above are not implemented yet.

For setup, see [local development](docs/local-development.md).
